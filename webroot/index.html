为什么 tailscale 控制台显示未授权?
★ 本机发起路由广播 (Exit Node 与 Subnet routes) 需 tailscale 管理后台管理员赋予【批准】(Approved) 状态。
👉 请在电脑或手机浏览器打开 Tailscale 控制台 ↗，找到本机，点击右侧 ··· -> Edit route settings，勾选批准 Subnet routes 与 Exit node 即可生效使用!
